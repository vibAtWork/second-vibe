How it works

  1. Upload CSV/TSV (any delimiter or encoding), Excel (.xlsx/.xls, all sheets) or JSON / JSON Lines.
  2. It is converted to one common table model: clean headers, ISO dates, typed columns, profiled values.
  3. Columns that look like personal data are flagged and given a suggested treatment: drop, mask, keyed hash, pseudonym, generalise, suppress rare values, round.
  4. Mark quasi-identifiers (age, postcode, sex…) to check k-anonymity live, and optionally drop rows in groups that are too small.
  5. Export to CSV, TSV, Excel, JSON, JSON Lines, SQL, HTML, a Frictionless Data Package for another institution, or Markdown for AI: context, data dictionary and data in one paste.

The detector is a helper, not a guarantee. Review every column before you share. Removing names does not make data anonymous on its own.
